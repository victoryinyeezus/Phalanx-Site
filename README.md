# Inbox OCD site

Static marketing site for Inbox OCD at [inboxocd.com](https://inboxocd.com). Plain HTML with no build step.

## Headers

`_headers` is generated by `.github/scripts/build_headers.py`. CI (`.github/workflows/headers.yml`) runs `build_headers.py --check` on every PR and push to `main`, so regenerate `_headers` after changing anything it covers.

## Download links

The download buttons in `index.html` and `thanks.html` point at the versioned installers on [inbox-ocd-releases](https://github.com/victoryinyeezus/inbox-ocd-releases/releases). After each desktop release is published, update all four links (Mac `.dmg` and Windows `.exe`, in both files) to the new version.

## Privacy page

`privacy.html` names the `Gridline` data folders on purpose: the app still stores data there under its legacy internal name.
